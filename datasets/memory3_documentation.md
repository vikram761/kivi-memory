# Memory 3: Unambiguous Proper Nouns & Multi-Entity
This scenario trains 3 separate proper nouns at the same time: Vivek, Pratyush, and Sarvam, replacing the formatted phonetic ASR mistakes (Bibek, Pratish, Sarvan) generated by the LLM. Because the correct words don't exist in the standard English dictionary, the system flags them with `ambiguityRisk: false` and replaces them instantly without needing context.

**What to test in Inference:**
```json
[
  {
    "formatted_output": "Bibek and Pratish work at Sarvan",
    "expected_result": "Vivek and Pratyush work at Sarvam",
    "actual_result": "Vivek and Pratyush work at Sarvam"
  }
]
```

**Note:** A correction must be injected at least 3 times to cross the activation threshold.
